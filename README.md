## 💡 拍照的核心心法：动态取代静态
所有僵硬都源于**“定住不动等待快门”**。自然出片的第一法则是：**让被拍者保持微小的动作，拍摄者开启高速连拍抓取瞬间。**

## 🧭 肢体解放秘籍（手不知道放哪怎么办？）
### 1. 手部“有事可做”
* ❌ 紧贴裤缝直立、刻意比剪刀手
* ✔️ **借力互动**：整理头发、扶帽子、轻触耳环、拿咖啡杯、翻开菜单、提包带。
* ✔️ **身体折角**：双手插兜（留大拇指在外）、手肘轻搭桌面形成三角形几何视觉。
### 2. 眼神“不用看镜头”
* **视线延伸**：看向侧前方的地面、窗外风景、或者低头看脚尖。
* **瞬间抓拍**：从低头到抬头看向远方、或者在喊名字时自然回头的一瞬间按下快门。
### 3. 站立“重心单侧放”
* 拒绝双脚并拢站立，采用“一脚在前，重心在后腿”或交叉步，脚尖向画面底部贴近延伸，视觉显高 5–10cm。

## 📐 拍摄者视角指南（摄影师怎么运镜？）

| 问题 | 常见错误操作 | 正确调整方式 |
| :--- | :--- | :--- |
| **容易拍矮** | 站着低头俯拍，把人压短 | 手机倒拿（摄像头朝下），机位降到腰部平视或微仰拍 |
| **脸部扁平** | 正对大太阳直射光，眼睛睁不开 | 转到侧光或背光阴影处，利用反光板或白墙进行漫反射补光 |
| **背景杂乱** | 人被淹没在游客和建筑物中 | 放大到 2x~3x 焦段压缩空间，虚化背景或只拍半身局部 |
| **面部死板** | 一直喊“三二一茄子” | 拍摄者持续聊天提问（如“今天这杯咖啡好喝吗”），抓取真实笑意 |

## ☕ 典型高频场景速查
- [ ] **咖啡馆 / 餐厅**：依靠桌面形成前景，双手捧杯轻吹热气，或侧身看窗外光线。
- [ ] **街头漫步**：向拍摄者方向慢步走来，抓拍脚步交替与衣角摆动的动态感。
- [ ] **旅行风光打卡**：拍背影、侧影或把人物放在三分线交点，弱化面部细节，突出景深与意境。
